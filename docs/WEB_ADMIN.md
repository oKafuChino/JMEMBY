# Komga Plus 网页管理面板

侧边栏提供“节点管理”：管理员可添加、编辑、启停、删除下载节点，查看在线状态、当前漫画及章节进度，并直接生成可复制的一键安装命令。每台 VPS 同时处理一本漫画。远程下载始终启用，首次使用需配置 Agent HTTPS 入口，安装器支持 Debian/Ubuntu/Alpine 原生服务，详见 [多 VPS 下载与网页安装](DISTRIBUTED_DOWNLOADS.md)。

面板提供用户与任务统计、注册/邀请码开关、用户组展示、封禁/解禁、双队列分页查看、取消任务及漫画下载来源查询。资格授权和白名单设置仍使用群聊回复命令 `/kk`、`/white`。

## 启用

在 `.env` 设置：

```dotenv
WEB_ENABLED=true
WEB_PORT=8080
WEB_PUBLIC_URL=https://admin.example.com
```

同步代码后执行 `docker compose up -d --build --no-deps app`。Compose 将端口绑定至 VPS 的 `127.0.0.1:8080`，需在 VPS 上用 HTTPS 反向代理转发至该地址。域名应专用于面板，不能带路径、查询参数或尾部路径。例如 Nginx 已配置证书的 server 内：

```nginx
location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
}
```

不使用公网域名时，可设置 `WEB_PUBLIC_URL=http://localhost:8080`，电脑执行 `ssh -N -L 8080:127.0.0.1:8080 user@vps`，浏览器打开 `http://localhost:8080`。浏览器地址必须与 WEB_PUBLIC_URL 完全匹配。非 Docker 启动默认只监听本机，可使用 WEB_HOST/WEB_PORT 配置。面板默认关闭；本版本启动时自动将数据库升级至 schema 9，升级前备份数据库。

## 登录与使用

### 节点连通性测试

在“节点管理”点击 **测试连通性**，最长等待 25 秒。节点实际回应探测后显示成功、响应耗时（含轮询等待）和测试时间；超时会提示检查服务、网络与 Agent 版本。下载中同样可以测试，不新增下载任务。测试接口仅管理员可用，沿用会话、Origin 与 CSRF 校验；旧 Agent 需更新后才能回应探测。

### 批量下载

登录后打开“批量下载”，粘贴每批 1–50 个漫画 ID 或配置允许的 HTTPS 链接（沿用 `PROVIDER_DOMAINS`），用换行、空格、英文/中文逗号或分号分隔。确认提交即授权下载，无需逐本点击 Telegram 预览按钮。输入上限 16000 个字符，50 项按原始输入条数计算。

后台逐项查询并入队，前端每 1.5 秒更新结果：等待、正在提交、已入队、跳过、输入无效或失败。批次内重复 ID（包括 ID 与链接指向同一作品）仅处理一次；单项失败不影响后续项目。已入队只是任务提交成功，实际下载/入库进度请在“下载队列”查看。

新任务归属当前登录管理员，通知发送到该管理员 Telegram 私聊；客户端不能指定他人身份、聊天或队列优先级。复用原有全局去重、双队列和归属规则：已下载或进行中的作品不创建新任务；具备白名单组别的发起人命中普通等待任务时只提升原任务，结果说明会标注已提升，原任务归属不变。管理员默认仍进入普通队列，不会因为网页提交自动获得优先权。

每位管理员同时仅可有一个未结束的提交批次，全站最多 8 个待处理/处理中批次，元数据查询串行执行。页面关闭或会话退出不会停止已接受的后台提交，刷新或重新登录会恢复该管理员最新批次。下载任务保存在现有数据库中，无需迁移。

批次结果保存在进程内，完成后保留约 1 小时（最多保留约 100 个批次）；服务重启会清除结果并停止尚未入队项目，不会取消已经入队的任务。重启或提交响应丢失后，可先查看下载队列/下载来源，再重新提交原清单，已有任务会按去重规则跳过。不要把批次结果显示为已入队理解成漫画已下载完成。

### 管理员登录

管理员私聊机器人发送 `/web` 获取登录码，然后在网页粘贴登录。登录码 5 分钟有效、仅用一次，重新获取后旧码失效；会话最长 8 小时，退出、服务重启或新的同账号登录会使原会话失效。只有 TELEGRAM_ALLOWED_USER_IDS 配置的管理员可获取登录码，各接口也重新校验管理员权限。普通用户、白名单、Telegram 群管理员不能登录。

页面支持手动刷新、用户和队列分页、普通/优先队列筛选。“下载来源”打开时自动显示最近 100 条下载任务（含所有状态），按提交时间倒序展示漫画标题、来源 ID、任务编号、发起用户 ID、姓名/用户名、队列、状态和提交时间。时间使用浏览器本地时区。

下载来源支持按漫画标题、漫画 ID、任务编号、用户 ID、姓名和用户名（可带 @）搜索；在全部历史任务中匹配，返回最近最多 100 条结果。清空搜索恢复最近任务，刷新保留当前搜索条件。搜索最多 200 个字符，百分号和下划线按普通字符匹配。仅管理员可访问；Telegram `/who` 查询不变。

封禁、解禁、取消任务、修改开关需要页面二次确认。取消任务保留已发布文件，封禁不撤销 Komga 账号权限。面板不返回 Bot token、Komga 密码、已有节点 Token 或邀请码。节点安装命令包含 30 分钟单次有效凭据，仅管理员可生成；退出登录后清空，勿分享给他人。

会话使用 HttpOnly、SameSite=Strict Cookie，HTTPS 模式启用 Secure；写操作校验 Origin 和 CSRF token，登录入口有全局频率限制。登录码只通过请求体提交，不放入 URL，HTTP 访问日志默认关闭。请勿将登录码分享给其他人。

验证边界：本地未安装 aiohttp/aiogram 时，HTTP 与 Telegram 路由集成测试会跳过；部署后验证管理员登录、普通用户拒绝、退出失效及任务操作。
