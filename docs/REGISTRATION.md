# 多用户注册交付记录

- `/register` 以 Telegram 提供的数字用户 ID 注册，不接受用户手填身份。仅私聊允许。
- 管理员沿用 TELEGRAM_ALLOWED_USER_IDS；无需注册，普通用户不能自助升级为管理员。
- users 表保存 ID、用户名、显示名称、注册 UTC 时间和禁用状态；settings 表保存注册开关，默认开放。
- schema 1 自动升级到 2；新库先创建旧任务表再升级，数据库中既有记录不删除。
- /admin 显示总人数（不含当前管理员）、有效人数、禁用人数、管理员人数和开关。
- /users 分页列出注册用户；/registration on|off 管理新注册；/ban、/unban 管理状态。
- 禁用和任务取消请求在同一事务落库；未确认下载按钮失效；任务取消由 worker 执行。解封不会撤销取消请求。
- 用户不能访问他人的任务；查询漫画期间被禁用会在返回后再次鉴权，不能生成新的确认按钮。
- 不自动创建 Komga 账号、不提供阅读权限绕过、不删除已下载的共享漫画。

验证：12 项用户注册/权限/迁移测试、26 项核心回归及 18 项适配器测试。源码编译检查通过。当前环境缺少 aiogram，Telegram 中间件/handler 的真实调用需部署后验证。

部署验收建议：管理员运行 /admin；第二个账号在注册前提交漫画应被拒绝，注册后可查询并下载；普通账号 /admin 应被拒绝；关闭注册后第三个账号无法注册；封禁用户不能点击旧确认按钮，解封后可正常使用。
